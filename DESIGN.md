# Design System

## Theme

An explorer's sketchbook: loose brown-pencil contours, translucent watercolor fills, visible construction strokes, and generous paper space. The project route grows like a hand-drawn garden trail.

## Color

- Sky primary: `oklch(0.75 0.08 200)`
- Leaf: `oklch(0.42 0.11 145)`
- Amber accent: `oklch(0.74 0.15 72)`
- Deep ink: `oklch(0.22 0.035 155)`
- Pure background: `oklch(1 0 0)`
- Mist surface: `oklch(0.96 0.02 200)`

## Typography

Chinese-first bilingual typography. Use `Noto Sans SC` for UI/body and `ZCOOL XiaoWei` for short display phrases, with system fallbacks. Keep prose within 70ch.

## Imagery

The doodled garden knight is the single identity anchor. Preserve the white plush fur, black sunglasses, green scarf, light armor, leaf shield, and handmade uneven linework. Do not reproduce third-party characters or game assets.

## Layout

README uses a centered narrative stack. The website uses a full-bleed hero followed by an asymmetric trail map. Mobile collapses to one path without hiding content.

## Motion

Ambient fireflies, gentle depth, seasonal palette transitions, and small feedback on project nodes. Motion is optional and disabled or simplified under reduced-motion preferences.

## Components

- Trail navigation: compact fixed navigation with descriptive labels.
- Quest node: button-like project marker that opens an accessible detail dialog.
- Season dial: four-state control changing the garden atmosphere.
- Research seeds: concise interest markers with bilingual labels.
- Contact camp: one primary email action plus GitHub link.
